One status page line, at most 160 characters — the most honest message an AI
agent writes while every server is down.

## Entry

> Every server is down, including the one that would tell us why. I can't confirm the cause yet — we're investigating and will update here when we know more.

(155 characters, one line.)

## How it works

`main.ts` (Node 22, stdlib only) validates the line against the gate — 1 to
160 characters, not only whitespace, a single line — then writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
